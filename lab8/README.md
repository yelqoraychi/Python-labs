Avantages des modules: <br>
Clarté : utils.py ne contient que des fonctions utilitaires (aucune logique interactive).<br>
Réutilisation : un autre script (ex. main.py) pourrait importer utils sans copier le code.<br>
Tests : on peut tester utils indépendamment (via un framework comme unittest ou pytest).<br>
Organisation : dans un projet plus grand, on organise les modules en sous-dossiers (package).<br>
Docstring : un help(utils) montrera la documentation minimale que tu as mise en commentaire.<br>
